# multi-action-swipe

## User prompt
Create an interactive multi-action swipe for Telegram chats with spring animations, haptics and configurable actions.

## Shared behavior contract
Implement functionally equivalent interactions on iOS and Android. Define gesture states, completion/cancellation, accessible alternatives, and realistic animation. No invented Telegram APIs. Independent runnable app is allowed.

## Acceptance
- Native runnable demo on iOS and Android
- Build commands and results documented
- Screenshots/video instructions
- No secret or private data
