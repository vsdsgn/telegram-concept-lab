# UX and animation acceptance bar
- Gesture must define touch-down, dragging, cancellation, threshold crossings, completion and interruption.
- Minimum 60 fps target; prefer native animations, avoid repeated heavyweight layouts.
- Good tactile feedback, safe destructive actions and clear visual affordances.
- Respect dark mode, screen density, Dynamic Type/font scale, Reduce Motion and TalkBack/VoiceOver.
- iOS and Android should have behavioral parity, not pixel identity.
- Build/run evidence, failure notes and short screen recording for each demo.
